## Hi, I'm Lucas Zarza

Head of Technology based in São Paulo, working where **software meets finance** in the energy sector.

I build the internal tools a finance team runs on: BI dashboards that replace spreadsheets,
APIs over PostgreSQL data marts, process automation, and the financial models behind investment decisions.

- **Product engineering** — full-stack TypeScript apps (Next.js + NestJS), from data model to UI
- **Data & BI** — SQL-heavy analytics APIs and KPI dashboards
- **Finance** — financial modeling, project finance and investment analysis
- **Automation** — Python scripts and tooling that remove manual work
